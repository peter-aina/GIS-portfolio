PROJECT 01 / HAZUS · HURRICANE

Hurricane Michael — Damage & Loss Assessment, Florida Panhandle

Region
Gadsden, Leon, and Wakulla counties · Florida Panhandle · county-level aggregation
Software
Hazus 7.0 (SQL Server backend) · Python (arcpy) · ArcGIS Pro
Question
How was building damage and economic loss distributed across the three Panhandle counties most affected by Hurricane Michael, what does the long-tail risk look like across return periods, and how much debris was generated?
Data sources
Hazus 7.0 default hurricane scenario tables (huSummaryDamage, huSummaryLoss), hzDemographicsB inventory, FEMA wind-field inputs, NOAA storm track.
Method
Queried Hazus SQL Server tables to extract damage state counts and dollar loss by general building type and occupancy. Joined results to county geometry in ArcGIS Pro. Applied the 1000x scaling factor on loss values and aggregated to county totals. Generated return-period loss exceedance maps for both economic and building loss at 10, 25, 50, 100, and 500-year intervals.

PROJECT 02 / HAZUS · FLOOD

Hamilton County Flood Risk — Central Indiana

Region
Hamilton County, Indiana · census-block-group level
Software
Hazus Pro (riverine flood module) · ArcGIS Pro · Python
Question
Which neighborhoods in Hamilton County face the greatest expected flood loss, and how does that risk overlap with socially vulnerable populations and critical infrastructure?
Data sources
Hazus Pro default flood depth grids · FEMA National Risk Index · ACS 5-year demographic estimates · county parcel inventory · DEM and road network layers.
Method
Ran a riverine flood scenario in Hazus Pro. Exported building-level loss estimates, aggregated to block group, and joined to a social vulnerability index built from ACS variables. Symbolized using a bivariate scheme (loss × vulnerability). Overlaid road exposure to identify access constraints during a flood event.

SECTION 04

Workflow & methods

The general workflow behind the maps on this site, for visitors who want to understand the methodology before evaluating any single project.

01 / SOURCE

Source data

All maps are built from publicly available or institutionally licensed datasets: FEMA Hazus and the National Risk Index, Census ACS and PUMS files, CDC datasets including BRFSS and WONDER, and state and local geospatial portals for parcel, hydrography, and boundary layers.

02 / PROCESS

Processing

Data are pulled, cleaned, and joined using Python (pandas, geopandas, arcpy) and SQL. For Hazus-based maps, the SQL Server backend is queried directly to extract damage and loss tables, which are then joined to spatial layers in ArcGIS Pro.

03 / CARTOGRAPHY

Cartography

Maps are finalized in ArcGIS Pro (or QGIS where appropriate). Symbology choices favor accessible color schemes and clear hierarchy: one primary variable per map, supporting context kept light.

04 / REPRODUCIBILITY

Reproducibility

Where possible, processing steps are scripted rather than clicked. Notebooks and scripts behind the maps are available on request.
