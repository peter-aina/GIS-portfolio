MAP 01 / HAZUS · HURRICANE

Hurricane Michael — Damage & Loss Assessment, Florida Panhandle

[ map image — full width 16:9 ]
Region
Gadsden, Leon, and Wakulla counties · Florida Panhandle · county-level aggregation
Software
Hazus 7.0 (SQL Server backend) · Python (arcpy) · ArcGIS Pro
Question
How was building damage and economic loss distributed across the three Panhandle counties most affected by Hurricane Michael, and which occupancy classes absorbed the most loss?
Data sources
Hazus 7.0 default hurricane scenario tables (huSummaryDamage, huSummaryLoss), hzDemographicsB inventory, FEMA wind-field inputs.
Method
Queried Hazus SQL Server tables to extract damage state counts and dollar loss by general building type and occupancy. Joined results to county geometry in ArcGIS Pro. Applied the 1000x scaling factor on loss values and aggregated to county totals.
Key finding
[Replace with your headline number — e.g., total estimated building loss reached $X million, with residential occupancy accounting for roughly Y%.]
What it shows
Choropleth of total economic loss by county, with proportional symbols overlaid showing the count of moderately-to-completely damaged buildings.
MAP 02 / HAZUS · FLOOD

Hamilton County Flood Risk — Central Indiana

[ map image — full width 16:9 ]
Region
Hamilton County, Indiana · census-block-group level
Software
Hazus Pro (riverine flood module) · ArcGIS Pro · Python
Question
Which neighborhoods in Hamilton County face the greatest expected annualized flood loss, and how does that risk overlap with socially vulnerable populations?
Data sources
Hazus Pro default flood depth grids · FEMA National Risk Index · ACS 5-year demographic estimates · county parcel inventory.
Method
Ran a 100-year riverine flood scenario in Hazus Pro. Exported building-level loss estimates, aggregated to block group, and joined to a social vulnerability index built from ACS variables. Symbolized using a bivariate scheme (loss × vulnerability).
Key finding
[Replace with your headline number — e.g., X block groups fall in the highest quartile of both estimated flood loss and social vulnerability.]
What it shows
Bivariate choropleth showing estimated flood loss on one axis and social vulnerability on the other. The darkest corner of the legend flags block groups warranting priority outreach.

PAGE 04

Workflow & methods

The general workflow behind the maps on this site, for visitors who want to understand the methodology before evaluating any single project.

01 / SOURCE

Source data

All maps are built from publicly available or institutionally licensed datasets: FEMA Hazus and the National Risk Index, Census ACS and PUMS files, CDC datasets including BRFSS and WONDER, and state and local geospatial portals for parcel, hydrography, and boundary layers.

02 / PROCESS

Processing

Data are pulled, cleaned, and joined using Python (pandas, geopandas, arcpy) and SQL. For Hazus-based maps, the SQL Server backend is queried directly to extract damage and loss tables, which are then joined to spatial layers in ArcGIS Pro.

03 / CARTOGRAPHY

Cartography

Maps are finalized in ArcGIS Pro (or QGIS where appropriate). Symbology choices favor accessible color schemes and clear hierarchy: one primary variable per map, supporting context kept light.

04 / REPRODUCIBILITY

Reproducibility

Where possible, processing steps are scripted rather than clicked. Notebooks and scripts behind the maps are available on request.
